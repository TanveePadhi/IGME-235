Escape Goblinland

navbar

Escape Goblinland is a pac-man themed game where you need to collect crystals and defeat goblins to get out. Now is there a way to get out? There isn't a specific way to get out at the moment this game is still under development but I plan to implement a way to "win" the game.

Instructions

You use the arrow keys to move. Collect crystals the light blue ones are worth 1 point. The yellow ones allows you to attack the goblins they are worth 5 point.
